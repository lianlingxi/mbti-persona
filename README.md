# 本色 · MBTI 人格探索

原创中文 MBTI 风格自我探索网站，包含 24 道题、四维偏好分析、16 型人格介绍、本机进度保存与重新测试。

## 使用
直接打开 index.html，或使用静态 HTTP 服务器访问。无需构建和安装依赖。

## GitHub Pages
在仓库 Settings → Pages 中，选择 Deploy from a branch，分支选择 main，目录选择 / (root)，保存即可。

## 说明
这是原创非官方问卷，未经标准化验证，仅供自我了解。回答保存在当前浏览器 localStorage 中。页面字体可从 Google Fonts 加载；不可用时使用系统字体。
